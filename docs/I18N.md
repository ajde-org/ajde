# Internationalization

AJDE-29 is being migrated incrementally. The [implementation checklist](plans/AJDE-29-macedonian-language-support.md), [coverage inventory](plans/AJDE-29-coverage.md), and [translation review register](plans/AJDE-29-translation-review.md) track remaining work. A language selector being present does not mean every flow is translated yet.

## Locale selection and rendering

`en` is the default; `mk` is Macedonian. An explicit selection calls the Zod-validated `changeLocale` server action, which stores `ajde_locale` for one year with Path=/, SameSite=Lax, HttpOnly, and Secure in production. Missing or unsupported values resolve to English. Browser language is not used. URLs and auth/share routes are unchanged.

`getLocale()` and `getI18n()` use request-scoped React caching, never a mutable global locale. The root layout sets the HTML language, passes only the selected catalog to `I18nProvider`, and localizes metadata. Next.js returns updated server UI after the cookie action without remounting the page; keep the provider unkeyed so form state survives switching. Components must not copy translated labels into long-lived state. Store error/message codes and interpolation values instead, as the login form does.

Reading the cookie in the root layout makes UI routes dynamic. The production build confirms this; image icon routes remain static. This is the tradeoff for cookie-localized content at the same URL. Do not put personalized localized HTML in a shared cache; include locale in keys for any localized data caches introduced later.

## Adding messages

1. Add a semantic, feature-prefixed key to the English catalog under `ride-share-app/lib/i18n/messages/`, with a complete message and named `{placeholders}`. Feature catalogs are composed into `en.ts`/`mk.ts`; keep imports of catalog types type-only in client modules.
2. Add the matching Macedonian translation and placeholders. `Messages` enforces matching keys and the catalog test checks placeholders. `t()` enforces the English message's parameters at compile time. Do not use dynamic unvalidated keys, HTML strings, concatenated sentence fragments, or a custom ICU syntax.
3. On the server, import `getI18n` from `@/lib/i18n/server` and await it. On the client, use `useI18n` from `@/lib/i18n/provider`. Client components need the provider; server-only modules must never enter their import graph.
4. Use `plural(locale, count)` for `.one`/`.other` messages in these two locales. Use native Intl through `lib/i18n/format.ts` for display. Keep ride time zone `Europe/Skopje`, money in MKD, and machine-facing IDs, enums and ISO values unchanged. Do not mechanically localize internal date calculations.
5. Add a review row for every new message and variant. Changing either language invalidates previous human approval. Review hash = first 12 hex characters of SHA-256(English + newline + Macedonian). A human must approve all fixed wording before PR creation.

Catalogs fail verification for missing keys rather than silently shipping incomplete Macedonian translations. Invalid locale input falls back to English. Original user content, brand names, and social-post screenshots are not translated; their application-authored accessible descriptions are.

## Tests and local browser checks

Component tests that render localized components can import `render` from `@/lib/i18n/testing`; it supplies English by default and accepts `{ locale: "mk" }`. Use explicit provider rerenders to test preserving state across locale changes. The helper is test-only.

Run the repository's test, lint and type checks from `ride-share-app/`, plus `npm run build`. The read-only smoke test below never signs in, sends email, or modifies database records. It tests invalid-domain validation, cookie persistence, independent browser sessions, direct auth redirects, form state, mobile navigation/calendar, and overflow at 375/1024/1440px. It writes screenshots to ignored `.scratch/ajde-29/`.

```powershell
npm.cmd run build
npm.cmd run start -- --port 3100
# In a second terminal:
node scripts/verify-i18n.cjs
```

If Playwright's browser is not installed, set `PLAYWRIGHT_CHROMIUM_EXECUTABLE` to a locally installed Chromium browser (for example Chrome). `I18N_BASE_URL` can select another localhost port. Authenticated lifecycle and database-changing flow tests require controlled test fixtures; preview deployments use production data.

No AI prompts or behavior have changed in the initial slice, so paid AI evals are not applicable yet. External Supabase auth-email wording and the treatment of persisted/generated AI prose remain open scope items in the plan.
